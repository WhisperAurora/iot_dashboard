# 物联网传感器数据实时监测平台

## 项目简介
基于 Python + Flask 搭建的物联网传感器数据监测系统，模拟温湿度传感器数据采集，通过 Web 页面实时展示数据变化趋势。

## 技术栈
- 后端：Python 3 + Flask
- 数据库：SQLite
- 前端：HTML + JavaScript + ECharts
- 多线程模拟传感器数据采集

## 功能
- 模拟温湿度传感器数据，每 5 秒自动生成一条记录
- SQLite 数据库持久化存储历史数据
- Web 页面实时展示当前温度、湿度数值
- ECharts 折线图动态展示数据变化趋势，每 5 秒自动刷新

## 运行方式
1. 安装依赖：`pip install flask`
2. 运行：`python app.py`
3. 浏览器访问：`http://127.0.0.1:5000`
